# Nightgram Android App Setup

This project is prepared for Capacitor. The React/Vite app remains the web source, while Capacitor wraps the production build as a native Android app.

## 1. Install dependencies

```bash
npm install
```

## 2. Create the Android project

Run these commands from the project root:

```bash
npx cap add android
npm run build
npx cap sync android
```

If you want generated app icons/splash assets, install the Capacitor assets tool and run it before syncing:

```bash
npm install -D @capacitor/assets
npm run mobile:assets
npx cap sync android
```

## 3. Open in Android Studio

```bash
npx cap open android
```

In Android Studio, wait for Gradle sync to finish, then select an emulator or connected Android phone and run the app.

## 4. Build a release app

For Google Play, build a signed Android App Bundle (AAB) from Android Studio. Do not share your signing key or passwords.

## Important

Nightgram currently uses Firebase Authentication and Firestore in the application code. The mobile wrapper does not replace that backend; it packages the existing React app.

The `android/` directory is intentionally generated by Capacitor on the machine where the dependencies are installed, rather than hand-written, because it contains Gradle/Android project files generated for the installed Capacitor version.
